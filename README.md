# Перо — редактор документов .docx и таблиц .xlsx

Настольное приложение для Windows (Electron + React + TipTap/ProseMirror).
Открывает и сохраняет документы Word (.docx) и книги Excel (.xlsx) собственным кодом импорта/экспорта, без сторонних конвертеров.

![Перо](docs/screenshot.png)

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev      # режим разработки: Vite + Electron с горячей перезагрузкой
npm test         # тесты импорта/экспорта docx
npm run dist     # установщик для Windows → release/Pero-Setup-<версия>.exe (тихо: /S, на машину: /S /allusers)
```

Тестовый файл `tests/fixtures/sample.docx` можно перетащить прямо в окно.

## Что уже умеет (v0.14)

- Открыть / создать / сохранить / сохранить как `.docx`, перетаскивание файла в окно, открытие двойным кликом (после установки).
- Текст: полужирный, курсив, подчёркнутый, зачёркнутый, очистка форматирования.
- Шрифт: гарнитура (список установленных шрифтов), размер, увеличить/уменьшить размер, цвет текста, выделение цветом,
  надстрочный и подстрочный; шрифт по умолчанию берётся из открытого документа (стиль «Обычный», тема оформления).
- Абзацы: выравнивание (лево/центр/право/ширина), стили «Обычный», «Заголовок 1–6»; интервалы до/после,
  межстрочный интервал (одинарный, 1,5, двойной, множитель, минимум, точно), отступы слева/справа/первой строки
  и выступ — кнопками, через диалог «Абзац» и линейкой; параметры «Обычного» берутся из открытого документа.
- Списки: маркированные и нумерованные, многоуровневые (Tab / Shift+Tab).
- Таблицы: вставка, строки/столбцы, удаление, объединение и разделение ячеек, ширина столбцов мышью;
  ширины столбцов из открытого файла, границы (все/внешние/внутренние/отдельные стороны, тип, толщина и цвет линии),
  заливка ячеек, выравнивание в ячейке по вертикали, высота строк, повтор строки заголовка, положение таблицы,
  выравнивание ширины столбцов; новые строки и столбцы получают оформление соседних.
- Гиперссылки (Ctrl+K), разрыв строки (Shift+Enter), табуляция.
- Отмена/повтор, буфер обмена, проверка орфографии (ru/en), масштаб, счётчик слов.
- Рисунки: показ рисунков из файла, вставка (кнопка «Рисунок», Ctrl+V, перетаскивание), изменение размера мышью
  и в сантиметрах, замещающий текст.
- Страницы: разбиение на листы по размеру и полям документа, колонтитулы (из файла и свои) с номерами страниц,
  вкладка «Макет» (поля, ориентация, размер бумаги), печать (Ctrl+P) и экспорт в PDF.
- Поиск и замена (Ctrl+F / Ctrl+H), с учётом регистра и «слово целиком».
- Стили: пользовательские стили абзацев (создать из абзаца, изменить — меняются все абзацы стиля, удалить),
  изменение «Обычного»; стили таблиц.
- Рецензирование: примечания (показ, создание, правка, удаление) и режим исправлений (запись правок,
  принять/отклонить по одной или все).
- Сохранность исходного файла: колонтитулы, сноски, комментарии, рисунки, поля, формулы, закладки, разделы
  и параметры страницы при сохранении переносятся без изменений (в тексте они показаны значками).
  Предупреждение с предложением сохранить копию — только если что-то действительно потеряется (исправления, элементы управления содержимым).
- Окна как в Word: каждый файл — своё окно, программа одна (повторный двойной щелчок по файлу открывает его
  в уже запущенном Пере); последние файлы (меню, вкладка «Файл», список переходов Windows).
- Автосохранение раз в минуту и «Восстановление документов» после сбоя или аварийного завершения.
- Журнал ошибок (`%APPDATA%\Перо\logs`) и «Сообщить о проблеме»: сведения для администратора — в файл и буфер обмена.
- Вёрстка как в Word: абзацы и таблицы делятся между страницами по строкам (запрет висячих строк, «не отрывать от
  следующего», повтор шапки таблицы), табуляции с позициями и заполнителями (линейка, диалог «Табуляция»), границы
  и заливка абзаца, колонтитулы первой страницы и чётных, разделы с книжной и альбомной ориентацией.
- Табличный редактор (.xlsx): несколько листов, формулы (около 50 функций, русские имена: СУММ, ЕСЛИ, ВПР…),
  ссылки на другие листы, ввод чисел, дат, процентов и рублей по-русски, числовые форматы, шрифт, заливка, границы,
  выравнивание и перенос, объединение ячеек, вставка/удаление строк и столбцов, сортировка, автосумма (Alt+=),
  копирование и вставка (в том числе из Excel), сумма/среднее/количество выделенного, печать и PDF.
- Формулы как в Excel: все функции Excel (523) с русскими именами — от СУММЕСЛИМН, ПРОСМОТРX, ТЕКСТ, ПЛТ до
  статистических распределений, комплексных чисел, ценных бумаг и функций Microsoft 365 (LAMBDA, MAP, ВСТОЛБИК,
  РЕГТЕСТ, ГРУПППО…); значения сверены с Excel (870 формул); ссылки на целые столбцы и листы, имена, динамические
  массивы (ФИЛЬТР, СОРТ, УНИК); пересчитываются только затронутые формулы, режим вычислений «вручную» и F9;
  подсказки при вводе, F4, мастер функций, вычисление формулы по шагам, стрелки влияющих и зависимых ячеек.
- Книги для ежедневной работы: маркер заполнения (ряды чисел, дат, месяцев, дней недели), автофильтр (Ctrl+Shift+L)
  и сортировка по нескольким столбцам, условное форматирование (больше/меньше/между, текст, повторы, первые N,
  цветовые шкалы, гистограммы), «Формат ячеек» (Ctrl+1) со своими числовыми форматами, найти и заменить (Ctrl+F/H),
  выпадающие списки и проверка вводимых значений, печать страницами как у Excel и предварительный просмотр (Ctrl+P).
- Сканер книг компании: `npm run scan -- <папка> --out отчёт.md` — какие функции используются в рабочих книгах,
  каких нет в Перо и совпадают ли значения Перо с сохранёнными Excel.
- Книги Excel сохраняются бережно: диаграммы, сводные таблицы, условное форматирование, проверка данных, имена,
  примечания остаются как были; закрепление областей, скрытие и группировка строк/столбцов, параметры страницы,
  область печати и сквозные строки, защита листа с паролем; открытие и сохранение CSV («;», UTF-8 и Windows-1251).

## Устройство

```
electron/main.cjs      окно, меню, диалоги, чтение/запись файлов
electron/preload.cjs   безопасный мост окно ↔ система
src/docx/import.js     docx → документ редактора (разбор OOXML: стили, нумерация, таблицы, ссылки)
src/docx/export.js     документ редактора → docx (генерация OOXML)
src/editor/extensions.js  схема документа
src/sheet/             табличный редактор: формулы, форматы, модель книги, xlsx, сетка, лента
src/Ribbon.jsx         лента: Файл / Главная / Вставка / Таблица
src/App.jsx            логика документа, диалоги, строка состояния
tests/                 round-trip тесты: импорт → экспорт → импорт + проверка python-docx
```

Модель документа — JSON ProseMirror. Любая новая функция добавляется в трёх местах:
расширение редактора → импорт из docx → экспорт в docx, плюс тест.
